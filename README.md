## 📌 Overview

**QuickCart** is a modern e-commerce web application designed to give customers a smooth, simple, and convenient online shopping experience.

The platform features a clean and responsive storefront where customers can explore popular products, discover featured collections, view product details, check ratings and prices, and easily browse everything on offer.

QuickCart also ships with a dedicated **Seller Dashboard**, giving sellers a centralized place to manage products, pricing, product images, and customer orders — all from one intuitive interface.

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/your-username/quickcart.git
cd quickcart

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env.local

# 4. Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
